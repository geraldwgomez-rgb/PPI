## Manual de Usuario

### Inicio de sesión y registro

El usuario, al entrar al menú de inicio, se va a encontrar con dos casillas: una donde debe ingresar un **correo** de cualquier tipo, y otra debajo de esa, donde debe ingresar una **contraseña** privada. Al completar esto, debe darle clic a la casilla **"Ingresar"**. Esto lo enviará al menú principal, donde se encontrará con todas las opciones que tiene para realizar dentro de la app.

### Pantalla principal

En este menú el usuario verá el resumen mensual de su dinero: el **total de ingresos**, el **total de gastos**, y un **balance monetario**, ya sea negativo o positivo. También habrá una comparativa con meses anteriores.

### Registrar un ingreso

En este menú el usuario se encontrará con diferentes campos seleccionables para realizar un ingreso:

- **Categoría**: para seleccionar de dónde viene el ingreso.
- **Monto**: para ingresar un valor de dinero.
- **Tipo**: para registrar si el ingreso es ordinario u ocasional.
- **Fecha**: para guardar un historial en orden cronológico.

Luego de completar cada campo, el usuario dará clic al botón **"Añadir ingreso"** y esto guardará todo. Al bajar en este menú, puede filtrar sus ingresos escribiendo palabras clave; más abajo, estará la lista de todos los ingresos realizados.

### Registrar un gasto

En este menú el usuario se encontrará con diferentes campos seleccionables para registrar un gasto:

- **Nombre del gasto**: para nombrar en qué utilizó su dinero.
- **Categoría**: para seleccionar de dónde proviene el gasto.
- **Monto**: para ingresar cuánto dinero gastó.
- **Tipo**: para registrar si el gasto es ordinario u ocasional.
- **Fecha**: para guardar un historial en orden cronológico.

Luego de completar cada campo, el usuario le dará clic al botón **"Añadir gasto"** y esto guardará todo. Al bajar en este menú, puede filtrar sus gastos escribiendo palabras clave; más abajo, estará la lista de todos los gastos realizados.

### Presupuestos

En este menú el usuario podrá añadir una meta o un límite de dinero que quiere lograr en un determinado tiempo:

- **Fecha de inicio**: el usuario elegirá en qué fecha iniciará su meta.
- **Fecha fin**: el usuario elegirá en qué fecha terminará su meta.
- **Monto límite**: el usuario podrá elegir el valor de presupuesto que desea ahorrar.

Luego de completar lo anterior, el usuario le dará clic al botón **"Guardar presupuesto"** y esto guardará todo. Al mirar más abajo en este menú, estarán todos los presupuestos que el usuario ha registrado.

### Soporte

En este menú, el usuario podrá recibir y enviar mensajes desde y hacia la administración. El usuario puede enviar mensajes dándole clic al botón **"Enviar mensaje"**; luego, en **Asunto**, el usuario escribirá la razón del mensaje; después de esto, describirá el problema o alguna sugerencia en base al asunto.

### Perfil

En este último menú, el usuario puede observar el **correo** con el que está utilizando la aplicación y, debajo de este, el **ID**, que es el código diferencial de cada usuario.

## Manual de Administrador

### Inicio de sesión

El administrador inicia sesión en la misma pantalla que el usuario. Al entrar al menú de inicio, se va a encontrar con dos casillas: una donde debe ingresar un **correo**, y otra debajo de esta, donde debe ingresar su **contraseña** privada. Al completar esto, debe darle clic a la casilla **"Ingresar"**. El sistema identifica el rol de la cuenta y, si corresponde a un administrador, lo enviará al panel de administración, donde encontrará todas las opciones disponibles para gestionar el sistema.

### Panel de administración

En este menú el administrador verá un resumen general del sistema con acceso directo a las tres secciones principales de su rol: **Gestión de usuarios**, **Soporte** y **Reportes y estadísticas**. Desde aquí puede desplazarse a cualquiera de estos menús.

### Gestión de usuarios

En este menú el administrador se encontrará con la **lista de todos los usuarios** registrados en el sistema. Para cada usuario, el administrador puede realizar las siguientes acciones:

- **Ver**: permite consultar los datos registrados del usuario seleccionado.
- **Editar**: permite modificar los datos del usuario, dando clic al botón **"Editar"**, realizando los cambios necesarios y guardando con el botón **"Guardar cambios"**.
- **Bloquear / Activar**: permite restringir o restablecer el acceso de un usuario al sistema, dando clic al botón **"Bloquear"** o **"Activar"** según el estado actual de la cuenta.
- **Eliminar**: permite eliminar de forma permanente la cuenta de un usuario, dando clic al botón **"Eliminar"** y confirmando la acción.

Al igual que en los demás menús, el administrador puede filtrar la lista de usuarios escribiendo palabras clave en el campo de búsqueda.

### Soporte (Administración)

En este menú el administrador podrá ver todos los mensajes enviados por los usuarios desde su propio menú de Soporte. Cada mensaje muestra el **correo del usuario**, el **asunto** y la **descripción** del problema o sugerencia. Para responder, el administrador debe seleccionar el mensaje y dar clic al botón **"Responder"**, escribir el contenido de la respuesta y darle clic al botón **"Enviar respuesta"**, con lo cual el usuario recibirá la contestación desde su propio menú de Soporte.

### Reportes y estadísticas

En este menú el administrador podrá visualizar los datos globales de todos los usuarios del sistema, entre ellos el **total de ingresos** y el **total de gastos** registrados por el conjunto de usuarios. También podrá revisar estos totales de forma comparativa entre distintos periodos de tiempo.

### Perfil (Administrador)

En este último menú, el administrador puede observar el **correo** con el que está utilizando la aplicación y, debajo de este, el **ID**, que es el código diferencial de su cuenta.
